HOW IT WORKS


1. SERVICE CREATION
   User creates service  API Server
    Service Registry registers service
    DNS adds service name  IP mapping
    Load balancer created for endpoints

2. POD CREATION
   User creates pod (with service selector labels)
    Kubelet reports pod to API Server
    Service Controller detects pod
    Matches pod selector to services
    Adds pod as endpoint
    Load balancer gets endpoint
